# App icon

NOTORYX PRO uses the NOTORYX icon with a **blue** glow, so it's easy to tell
apart from NOTORYX Core (orange) and NOTORYX Independent (silver).

| File | Used for |
|---|---|
| `notoryx-pro-icon-blue.png` | Full icon: Android legacy launcher icons and iPhone icons (flattened, since iOS icons can't be transparent) |
| `notoryx-pro-icon-foreground-blue.png` | Android adaptive icon foreground, inset 16% on a `#0A1C22` background |
| `notoryx-pro-icon-macos-blue.png` | Mac app icon |

All three are 1024 x 1024: the NOTORYX app artwork with the hue turned
3.4 radians (orange to blue) using Core Image's hue adjust filter.
